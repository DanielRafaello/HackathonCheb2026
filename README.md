# Kde na západě

Kde na západě je interaktivní geografická hra, ve které hráči pomocí nápověd objevují zajímavá místa Karlovarského kraje. Za správné tipy získávají hvězdičky, sbírají místa do osobní mapy a jejich návštěvou odemykají další zajímavosti. Projekt propojuje otevřená data kraje se zábavou a motivuje k poznávání méně známých lokalit.
